Your access

Client links

A client link opens the full builder so a white-label developer can design and preview, but hides the download, the dashboard and the admin settings. Add a label so you can tell links apart in your own records.

—
This hides the download; it does not encrypt the app. A determined person can still read the page source, because the browser has to download the code to run it. Real protection needs a small hosted backend.

Selling the theme

Buyers pay through your own Stripe or PayPal link, then you give them the passcode. Set these once here and the builder uses them.

This browser's usage

Counters are stored locally by the builder, so this shows what has been done in this browser only.

Tracking other people's accounts and usage needs a hosted backend. Nothing here can see what a client does in their own browser.

Hosting a separate client copy

  • Copy index.html into a new GitHub repo, or a folder such as /client-a/ in this one.
  • Turn on GitHub Pages for it, then share that URL with ?client=1 on the end.
  • Change DL_PIN in that copy before sharing widely, so one leaked passcode does not unlock every copy.
