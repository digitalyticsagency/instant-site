Instant Site — Admin

Your control page. Not linked from the app and marked noindex, but it is a public file on a public site — so nothing secret is stored in it. The admin token you enter below is kept in this browser and sent only to your own Worker.

Your access

There is no passcode any more. Issue yourself a licence below, labelled so you can tell it apart, then enter it once on the builder's Download button. It is checked by the Worker and you can revoke it from this page if it ever leaks — none of which was true of the passcode this replaced.

Licence keys

Issue one key per customer. Each key can be revoked on its own, so a leaked key costs you that customer and not every customer. Keys are stored in your Cloudflare database, not in this page.

—
This gates the download and gives you real per-customer usage. It is not DRM: the theme is built in the customer's own browser, so the Worker never handles the file and cannot withhold it from someone who edits the app's JavaScript.

Client links

A client link opens the full builder so a white-label developer can design and preview, but hides the download, the dashboard and the admin settings. Add a label so you can tell links apart in your own records.

—
This hides the download; it does not encrypt the app. A determined person can still read the page source, because the browser has to download the code to run it. Real protection needs a small hosted backend.

Selling the theme

Buyers pay through your own Stripe or PayPal link, then you issue them a licence key above and send it over. Each buyer gets their own key, so a leaked one can be revoked without affecting anyone else.

This browser's usage

Counters are stored locally by the builder, so this shows what has been done in this browser only.

Tracking other people's accounts and usage needs a hosted backend. Nothing here can see what a client does in their own browser.

Hosting a separate client copy

  • Copy index.html into a new GitHub repo, or a folder such as /client-a/ in this one.
  • Turn on GitHub Pages for it, then share that URL with ?client=1 on the end.
